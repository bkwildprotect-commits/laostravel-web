# W2.7 Infrastructure Provider Evaluation — 25 Sep 2026

## Decision status
Architecture remains provider-neutral. No production account, billing plan, database, auth tenant, storage bucket or hosting project is created by this document.

## Current shortlist
### Supabase
Candidate for shared PostgreSQL + Auth + private Object Storage. It maps closely to the existing PostgreSQL schema and can serve both Next.js and Flutter. Current public pricing must be rechecked immediately before purchase/production activation.

### Cloudflare
Candidate for edge/API protection and potentially web/API hosting. Workers has a free tier and a low-cost paid tier, but adopting Workers as the application runtime changes deployment/runtime assumptions and should be benchmarked before commitment.

### Vercel
Strong Next.js deployment fit, but LaosTravel is a commercial platform. Vercel states Hobby is for non-commercial personal use, so production LaosTravel must not be planned on Hobby. Pro/current commercial terms must be rechecked before purchase.

### Neon
PostgreSQL candidate worth retaining for comparison if LaosTravel chooses separate auth/storage providers. Do not select solely on free-tier pricing.

## Selection gates
1. One shared backend usable by Website, Android and iOS.
2. PostgreSQL compatibility and transactional booking/inventory locking.
3. Secure authentication and account recovery.
4. Private partner-verification document storage with authorization.
5. Server-side API/secrets; no privileged keys in browser or mobile builds.
6. Backups/recovery, logs/auditability, rate limiting and cost controls.
7. Practical latency/reliability for Laos users and future regional expansion.
8. Clear commercial terms and predictable pilot-to-growth pricing.
9. No vendor-specific rewrite of core business rules.
10. Payment provider remains a separate decision.

## Implementation recommendation for the next build gate
Prepare an adapter boundary first: database, auth and object-storage interfaces plus environment validation. This lets LaosTravel run provider-neutral contracts while a real provider account is selected. Do not create a fake production backend.

## Purchase/activation gate
Owner approval is required before any paid plan, production domain, production database, auth provider, storage provider or payment provider is activated.
