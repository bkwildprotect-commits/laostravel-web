# W2.8 Provider Adapter Layer

The application now has provider-neutral boundaries for database, authentication and private object storage.

- Provider SDKs must be implemented behind these interfaces.
- UI and booking business rules must not import vendor SDKs directly.
- Secrets remain server-only environment variables.
- GET /api/health reports setup_required until required environment values exist.
- A configured environment does not by itself prove a live provider connection; real adapters must perform provider-specific connectivity checks when selected.

This stage deliberately does not create a production database, auth tenant, storage bucket or paid account.
